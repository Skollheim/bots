# Bots

Bots is the desktop companion for [Boite](https://github.com/beboite/boite): little robots that sit on your desktop, watch your agents work and let you talk to them without opening Boite's window.

Bots is a Boite plugin. Boite installs it from Settings > Plugins, starts it with its own window, and hands it the address of the Boite core and a token to talk to it.

Work in progress: the first version is being moved here from Boite's companion experiment.
